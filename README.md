A faster drop-in for make.fun's makefun-site 1.0.0 static site generator — identical output on every case, less CPU time. A single dependency-free `solve.js` re-implements the build (front matter, Markdown subset, template dialect, slugs, collections, tags, report) with bulk HTML escaping, a single-pass Markdown renderer, ASCII fast paths in slugify, and cached page/card objects.

## Run it

```sh
MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
